# 动态加载模块无法被字符串 patch 目标

## WHERE（适用场景）
对运行时动态加载的模板引擎、插件系统或热重载模块进行单元测试 mock 时。

## HOW（核心实现）
1. 放弃字符串式 `@patch`，改用直接属性赋值 + `addCleanup` 恢复；  
2. 示例：`self.addCleanup(setattr, tmpl_lib, "_CONTRACTS_FILE", original)`；  
3. 若需多处复用，封装为上下文管理器 `with patched_attr(tmpl_lib, "_CONTRACTS_FILE", value): ...`。

## WHEN（触发条件 / 危险信号）
- `patch("xxx.yyy")` 在测试中静默失效（mock 未触发，原函数仍执行）；  
- `assert_called_once()` 永远失败，但 `print(sys.modules.keys())` 显示目标模块名缺失；  
- 使用 `importlib.util` / `zipimport` / `exec()` 动态加载模块后开始写测试。
