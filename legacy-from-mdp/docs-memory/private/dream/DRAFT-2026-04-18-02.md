# macOS tmp_path 路径归一化失败的防御性处理

## WHERE（适用场景）
在跨平台测试中需打印或日志化临时路径相对于项目根目录的相对路径（如调试输出、postcheck 报告）；尤其当 `_ROOT` 硬编码为 `/var/folders/...` 或未做 `/private` 前缀兼容时。

## HOW（核心实现）
1. 所有 `p.relative_to(_ROOT)` 调用必须包裹 `try: ... except ValueError: return str(p)`；  
2. 不应修改 `_ROOT` 为 `/private/var`（破坏 Linux/Windows 兼容性）；  
3. 日志中明确标注降级原因（如 `"fallback to abs path (macOS /private mismatch)"`）。

## WHEN（触发条件 / 危险信号）
CI 在 macOS 上 pytest 失败，报 `ValueError: '/private/var/folders/...' is not in the subpath of '/Users/.../mms'`；或本地开发时相对路径日志为空/异常。
