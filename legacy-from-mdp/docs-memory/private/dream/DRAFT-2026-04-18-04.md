# Python 模块级变量跨条件块可见性陷阱

## WHERE（适用场景）
编写含条件分支且需共享中间变量的配置/模板生成逻辑时（如 draft list 构建与空检查分离）。

## HOW（核心实现）
1. 避免“先 if 定义、后同级检查”结构；统一前置声明（如 `drafts = []`）；  
2. 或将检查逻辑移入同一作用域块内（如 `if list_drafts: ...; if drafts:`）；  
3. 启用 `pylint:unreachable`, `pylint:undefined-variable` 等静态检查覆盖此路径。

## WHEN（触发条件 / 危险信号）
- 出现 `UnboundLocalError` 且报错行无显式赋值；  
- 代码含 `if cond: x = ...` 后紧跟同缩进 `if not x:` 或 `x.append(...)`；  
- 覆盖分支测试时仅部分路径通过，CI 报错与本地行为不一致。
