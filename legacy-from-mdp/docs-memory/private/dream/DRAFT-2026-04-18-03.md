# 动态加载模块的 patch 失效与直接赋值替代方案

## WHERE（适用场景）
测试动态加载的模板引擎、插件系统或热重载模块（如 `template_lib`）时，需 mock 其内部常量（如 `_CONTRACTS_FILE`）；或构建隔离的单元测试沙箱。

## HOW（核心实现）
1. 保存原值：`original = tmpl_lib._CONTRACTS_FILE`；  
2. 直接赋值：`tmpl_lib._CONTRACTS_FILE = contracts_file`；  
3. 使用 `pytest.fixture` 或 `with contextlib.suppress()` 确保恢复：`tmpl_lib._CONTRACTS_FILE = original`。

## WHEN（触发条件 / 危险信号）
`patch("template_lib._CONTRACTS_FILE")` 不生效，断点验证目标值未变；或测试通过但实际运行时行为异常——说明 mock 未触达真实模块对象。
