# macOS tmp_path 路径归一化导致 relative_to 失败

## WHERE（适用场景）
在跨平台测试中对临时路径做相对路径展示（如日志、调试输出、diff 引用）时。

## HOW（核心实现）
1. 所有 `path.relative_to(root)` 调用必须包裹 `try/except ValueError`；  
2. 降级策略：捕获后返回 `str(path)`（绝对路径）并加注 `# macOS symlink resolution`；  
3. 测试需显式覆盖 `platform.system() == "Darwin"` 分支，验证降级逻辑。

## WHEN（触发条件 / 危险信号）
- pytest 在 macOS CI 上 `relative_to()` 报 `ValueError: '/private/var/...' is not in the subpath of '/Users/...'`；  
- 本地 Linux/macOS 行为不一致，且路径打印突然变为绝对路径；  
- `tmp_path` 相关断言在 macOS 上随机失败。
