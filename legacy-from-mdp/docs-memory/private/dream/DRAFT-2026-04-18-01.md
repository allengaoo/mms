# Python 模块级变量跨条件块可见性陷阱

## WHERE（适用场景）
编写含条件分支的配置/初始化逻辑时，需在分支内外共享变量（如 drafts、config_obj）；或复用 EP-117 类前向引用模式的脚手架代码。

## HOW（核心实现）
1. 统一在函数顶部显式初始化变量（如 `drafts = None`）；  
2. 避免“仅在 if 中赋值 + 同级 else/if-not 引用”的隐式局部化结构；  
3. 用 `isinstance(drafts, list)` 替代 `if not drafts:` 前置校验，但根本解仍是初始化。

## WHEN（触发条件 / 危险信号）
pytest 报 `UnboundLocalError` 且 traceback 指向与条件判断同级的变量引用；或静态分析工具（如 pyflakes）警告 “local variable referenced before assignment”。
